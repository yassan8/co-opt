# Fizeau interferometer — 操作とモデルの範囲

`Fizeau_Interferometer.json` は、平面測定用の **2光束近似** のフィゾー干渉計です。
測定面からの最初の反射と、基準面からの反射を、同じカメラ上で干渉させます。

## 読み込み・計算

1. `File → Load…` から `Fizeau_Interferometer.json` を読み込みます。
   ローカル開発版の `File → Examples` にも表示されます。
2. `Analysis → Simulation → Coherent Signal` を開きます。
3. Detector に `Fizeau Camera` を選び、`Run` を押します。
4. 部品の位置・角度を変更したら、再び `Run` を押します。

| Configuration | 内容 | 確認するもの |
| --- | --- | --- |
| 1: tilted flat | 測定面の Rot X = 0.02° | 横方向に延びる直線縞。Y方向の周期は約0.906 mm |
| 2: parallel flats | 測定面の Rot X = 0° | 照明範囲内の位相は一様。測定面Zの移動による明るさの変化 |

Config 2 で `Test flat` の **Position Z を 101 → 101.0001582 mm** にすると、
測定面は λ/4 = 0.1582 µm 移動し、往復OPDが λ/2 変わって干渉項の符号が反転します。
表示画像は毎回自動スケールされるため、**Detected（W）も比較してください**。
平行光・平行平面では、Zを動かすだけで円形縞にはなりません。

## 光学構成

- 光源：632.8 nm 単色、平行光、Gaussian強度分布、ビーム径4 mm、100 µW。
- 50:50 キューブ：中心 (X,Y,Z) = (0,0,0) mm。入射光を+Zへ透過し、戻り光を−Xのカメラ側へ反射。
- 基準板：N-BK7、厚さ5 mm。入射面は Z=75 mm、反射率4%の裏面基準面は Z=80 mm。
  入射面は理想AR面として扱います。
- 測定面：基準位置 Z=100 mm、反射率4%。部品中心のPosition Zは101 mm、厚さは2 mmです。
- カメラ：理想レンズ f=50 mm のリレー、128×128画素、ピッチ40 µm、露光1 µs。
- 各経路4,096本、合計8,192本をカメラ信号計算に使います。

基準光は「基準板に入射 → 裏面基準面で反射 → 基準板を戻る」経路です。
測定光は「基準板を透過 → 測定面で反射 → 基準板を戻る」経路です。
基準板内の往復は共通であり、平行面・軸上では20 mmの空気間隔の往復だけが差となり、物理OPDは40 mmです。
OPD校正値は0です。コヒーレンス長が40 mmを超える単色レーザーを想定しています。

### 基準板の Rot Y = −135° について

現行のPlate BeamSplitter部品は、局所座標内で法線が45°の面として定義されています。
この局所定義を補償するため、基準板のRot Yを−135°としています。
**実際の基準面はグローバルZ軸に垂直です。斜め入射の基準板ではありません。**
`reference-flat` のラベルに示した Z=80 mm が基準面の位置です。

## 検証と制限

- 両Configとも4,096/4,096本が各光路から到達、飽和画素0。
- Config 1の直線縞を理論的な位相勾配と比較。
- 測定面を1 µm移動するとOPDが2 µm変化。
- 基準板の屈折率を変えても、平行面・軸上の両経路OPD差は不変。
- Config 2のλ/4移動で、カメラ画素の干渉項の符号が反転。

反射率・透過率は指定した定数で、材料中の伝搬には波長依存屈折率を使います。
高次の共振器内往復、偏光、膜構造からの複素反射係数、完全な開口回折は含みません。
この例は干渉信号の確認用です。カメラ画像からの面形状復元や絶対高さ測定を実装・検証した例ではありません。
