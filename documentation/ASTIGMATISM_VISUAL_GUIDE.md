### RMS計算の詳細

```
┌─────────────────────────────────┐
│ RMS計算（横収差RMS）             │
└─────────────┬───────────────────┘
              │
              ↓
    FOR Z = Z_start to Z_end:
              │
              ↓
    ┌─────────────────────────┐
    │ 各光線の像面交点を計算    │
    │ spot_i = (x_i, y_i)     │
    └─────────┬───────────────┘
              │
              ↓
    ┌─────────────────────────┐
    │ 主光線交点                │
    │ chief = (x_c, y_c)      │
    └─────────┬───────────────┘
              │
              ↓
    ┌─────────────────────────┐
    │ RMS計算                  │
    │ RMS = sqrt(             │
    │   Σ[(x_i-x_c)²+(y_i-y_c)²] │
    │   / N                   │
    │ )                       │
    └─────────┬───────────────┘
              │
              ↓
    ┌─────────────────────────┐
    │ 最小値更新               │
    │ if RMS < min_RMS:       │
    │   min_RMS = RMS         │
    │   best_Z = Z            │
    └─────────┬───────────────┘
              │
              ↓
          END LOOP
              │
              ↓
    ┌─────────────────────────┐
    │ best_Z を返す            │
    └─────────────────────────┘
```

## 主光線定義の違い

### 1. Stop Center（絞り中央通過）

```
   瞳（Stop）
┌────────────┐
│            │
│     ●──────┼────→ 主光線
│   中心     │
└────────────┘

- 従来の標準定義
- 絞り中心を通る光線
```

### 2. Beam Center（光束巾の真ん中）

```
   像面
   ┌──●──┐  ← x_max
   │  ●  │
   ●──●──●  ← 光束
   │  ●  │
   └──●──┘  ← x_min
      ↑
   beam center = (x_max + x_min)/2
```

### 3. Centroid（光束の重心）

```
   像面
   ●  ●  ●
   
   ●  ●  ●  ← 全光線の平均位置
   
   ●  ●  ●
      ↑
   centroid = Σ(x_i, y_i) / N
```

## 実際の非点収差曲線例

### Case 1: 良好な光学系（低非点収差）

```
θ (deg)
  30│  S●──────────────
     │   M●────────────
  20│  S ●─────────────
     │   M ●───────────
  10│  S  ●────────────
     │   M  ●──────────
   0│  S●M●───────────→ Position (mm)
     │ -0.1  0  +0.1
     
特徴:
- MとSの差が小さい（非点収差小）
- 両曲線とも0に近い（球面収差も小）
```

### Case 2: 非点収差が大きい系

```
θ (deg)
  30│       M●────────────
     │  S●───────────────
  20│      M ●──────────
     │  S  ●────────────
  10│     M  ●─────────
     │  S   ●──────────
   0│  S●M●────────────→ Position (mm)
     │-0.5 0  +0.5
     
特徴:
- MとSの間隔が大きい（非点収差大）
- 画角が大きいほど差が増加
```

### Case 3: 像面湾曲が大きい系

```
θ (deg)
  30│           M●──────
     │          S ●─────
  20│        M●────────
     │       S ●───────
  10│     M●──────────
     │    S ●─────────
   0│  M●──────────────→ Position (mm)
     │S●  +0.5  +1.0
     
特徴:
- 全体的に正方向にシフト（像面湾曲）
- MとSの間隔は比較的小さい
```
