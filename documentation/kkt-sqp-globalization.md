# KKT-SQP Globalization

The default Optimize selection is AL + Gauss-Newton using the July 27 TypeScript route. Selecting AL-GN does not start KKT-SQP afterward. The route is forced to TypeScript so native optimizer changes cannot replace the historical AL-GN implementation. KKT-SQP remains an isolated finite-restoration SQP run with no automatic AL-GN stage, preserving its v35 convergence and reporting behavior.

## Method

The TypeScript KKT-SQP route follows the Byrd-Omojokun trust-region SQP lifecycle for expensive optical objectives:

1. Build the direct Requirement-score gradient, active-constraint Jacobian, and Powell-damped BFGS Hessian at the current accepted point.
2. Apply Jacobi diagonal QP preconditioning.
3. Starting from the persistent model damping, search a temporary DLS multiplier so the normalized physical QP step lies near the active trust-region boundary.
4. Evaluate the full trust-region step once.
5. If it is rejected, retain all derivatives, contract the radius by 0.5, re-solve the QP, and evaluate one new full step. This changes the step direction instead of only shortening the rejected direction.
6. Update the radius from actual versus predicted reduction. Derivatives and BFGS state are updated only from accepted points.

The scalar objective used by the model, acceptance test, gain ratio, and console is identical. If `c_i` is the worst contribution for Requirement `i`, finite differences are taken directly on the stable contribution vector and the objective is `sum(c_i) = Min.`. The SQP gradient is the sum of those contribution derivatives. This avoids both the former aggregation mismatch and the artificial Gauss-Newton curvature introduced by representing the linear score as `sqrt(c_i)` residuals.

Gain-ratio prediction first uses the current BFGS quadratic model. If that prediction is nonpositive or below the numerical reliability threshold, the optimizer falls back to the direct first-order prediction $-g^T s$ when it is reliable. This preserves the trust-region meaning of `rho` for an improving step whose curvature model is temporarily unsuitable, instead of reporting `rho = 0`, suppressing BFGS updates, and forcing an unnecessary derivative refresh.

Powell-damped BFGS curvature is updated after every sufficiently long accepted SQP step that measurably lowers `Min.`, including a step whose gain ratio is unavailable. The update is not applied to rejected, short-backtracked, or score-neutral steps. This prevents early genuine improvements from being discarded solely because the initial curvature model could not yet produce a reliable `rho`.

The production optical path reuses accepted-point first derivatives with a Broyden rank-1 update because a full finite-difference Jacobian is dominated by expensive optical evaluations. It refreshes finite-difference columns on poor models and rejection recovery, and performs periodic full refreshes. Set `kktSqpFreshJacobianEachAcceptedIter: true` to use the stricter standard-SQP derivative lifecycle for diagnostics. Powell-damped BFGS remains separate and approximates Lagrangian curvature, not first derivatives.

With no explicit nonlinear constraints, the Byrd-Omojokun normal step is zero and the method reduces to a trust-region BFGS-SQP step. With active constraints, the current dense EQP/KKT solve computes the combined feasible SQP step; a separate projected-CG tangential solver is not claimed. The measured finite-difference probe fallback is an explicit restoration extension, not part of the core Byrd-Omojokun iteration. It is used only after the model step and contracted retry both fail, following the restoration principle described by modern funnel SQP methods.

Trust-region mode does not run the legacy model-gradient or coordinate-probe recovery after the contracted retry. If both trials fail, the contracted radius and current-point derivatives are retained for the next iteration. Primary and contracted solves both target 90% of the active boundary. A successful contracted retry with a reliable boundary-quality gain ratio uses the normal measured-step expansion rule, up to approximately `2x` the accepted normalized step. This prevents repeated reject/retry cycles from ratcheting the radius toward zero and forcing increasingly large temporary QP damping while requiring measured model agreement before expansion.

The normalized radius can contract below the former hard floor of `0.01`. Its default minimum is `1e-6`, configurable with `kktMinimumTrustRegion` in the range `1e-12` through `0.1`. Every retry, rejection, rollback, backtrack, and gain-ratio update uses this same minimum. This follows trust-region SQP convergence logic: a rejected step must be allowed to contract until the local model is accurate or the algorithm reaches a small-step termination scale.

After a deep contraction, an accepted step with `rho >= 0.3` expands the radius by approximately `2x` only when the normalized step reaches at least 80% of the current trust boundary. Interior steps leave the radius unchanged. This prevents the former `1.1x` update from spending dozens of accepted iterations recovering from a small radius while avoiding unjustified expansion when the unconstrained local step is already inside the region.

Trust-region trials remain inside the modeled radius by default. A reliable boundary step is accepted at `alpha=1`, then the next radius grows according to its measured gain ratio. Repeated `alpha=2` extrapolation is not standard trust-region behavior: it can travel outside the modeled neighborhood while leaving the radius unchanged, producing a long sequence of nearly identical optical improvements. Extrapolation remains available only as the explicit experiment `kktSqpStepLookahead: true`.

The restoration trigger is adapted to expensive optical objectives. When best-score improvement stays below 0.1% for four iterations, the outer watchdog first performs a same-point fresh rebase equivalent to the productive part of manual Stop/Run: multipliers, penalty, damping seed, trust radius, Jacobian, BFGS state, attempted trials, and the evaluation cache are reset without perturbing the best design. If the fresh proof window is still unproductive, the watchdog enters deterministic Qcon orthogonal restoration independently of the temporary `QPDamp`; a separate high-damping watchdog remains as a fallback only while no outer restoration lifecycle is active, so it cannot reset the bounded attempt counter. Restoration requires at least two active Qcon coefficients but does not require every optimization variable to be Qcon: thickness, curvature, and other mixed variables remain fixed during the Qcon poll. Distinct DCT modes are tried before opposite signs (`mode 0+`, `mode 1+`, ..., `mode 0-`, `mode 1-`, ...), because immediately trying `mode 0-` after a productive `mode 0+` can revisit the same optical valley while never testing another coupled Qcon direction. The default attempt budget includes both signs of every active mode. For each mode, the optimizer measures a bounded three-amplitude poll derived from the initial trust radius and Design Intent scales. With the default radius this samples `0.5x`, `1x`, and `2x` the configured Qcon scale, then commits only the lowest filter-merit candidate. If every Qcon mode is unproductive, one bounded projected Cauchy poll uses the objective gradient at the exact best-point key across all active variables. Both signs and the same three amplitudes are evaluated after bound projection, allowing thickness, curvature, and Qcon coefficients to move together without using a stale gradient or an unevaluated jump. Each selected seed receives a four-iteration proof window. A material best-score improvement resets the lifecycle. After all bounded recovery is unproductive, the optimizer performs one final best-point polish rebase. A second plateau restores the best point and stops, so this polish cannot cycle indefinitely.

Restoration administration and its proof window use a separate finite recovery allowance instead of consuming the tail of the requested major-iteration budget. Starting a same-point rebase, Qcon restoration mode, mixed-variable Cauchy poll, or best-point polish adds one reset iteration plus the configured stagnation window to the internal limit. The default cap includes every Qcon attempt plus one window for each of the other three stages; `kktSqpMaximumRecoveryIterations` can set an explicit cap. The same finite allowance prevents the requested iteration boundary from terminating a still-productive trajectory: when an iteration inside the final proof window accepts a best-score decrease above the configured stagnation threshold, one proof window is added. Further windows require fresh material progress and remain bounded by the existing recovery cap. User Stop, wall-time limits, and an explicit `kktHardIterCap` remain authoritative.

An outer-iteration Requirement-score watchdog applies the same four-iteration progress window before trial construction. It is intentionally independent of accepted merit changes, rejected optical trials, and no-evaluation model-refresh `continue` paths. This prevents a cycle of cached zero-displacement iterations and score-neutral constraint-merit steps from resetting or bypassing restoration while `Min.` remains unchanged. Sampling-fidelity transitions and completed restorations reset this watchdog because they establish a new objective or local model regime.

A Qcon restoration is allowed one progress window to prove that the new basin lowers the best Requirement score. This preserves successful escapes where the perturbation itself is not better but the first rebuilt SQP model is. If the next four-iteration plateau arrives without a material best-score improvement, the optimizer restores `bestX` and terminates instead of cycling through more orthogonal modes and rebuilding expensive optical Jacobians indefinitely.

System Console iteration rows follow accepted-iterate reporting: the initial score is shown, then only accepted events that establish a numerically lower best `Min.` are appended. Rejected trials, no-evaluation model refreshes, and score-neutral constraint-merit accepts remain available to optimizer state and profiling but do not produce repeated score rows. `Improv.` is the absolute Requirement-score decrease between consecutive displayed rows, `previous Min. - current Min.`. It is not a fractional ratio, so skipped internal iterations do not make the column disagree with the visible score values. Outer recovery stages are printed separately (`sqp-same-point-rebase`, `sqp-qcon-restoration-N`, `sqp-best-point-polish`, or `sqp-restoration-exhausted`) so a sparse accepted-only table does not hide why a late run continued or stopped.

Scalar and native-batch evaluations construct the same worst-per-Requirement contribution vector. Their objective, displayed `Min.`, and finite-difference Jacobians therefore use one merit definition; native parity checks no longer compare different score models.

The console reports `DFseed` and `QPgain`. `DFseed` is the persistent model regularization seed; trust-region optical rejects do not increase it. Internally, the temporary More-Hebden multiplier $\lambda$ enforces the current trust boundary for one iteration and is then discarded. Because Jacobi preconditioning normalizes the QP diagonal near one, the console converts the raw multiplier to the bounded step-gain convention $\mathrm{QPgain}=1/(1+\lambda)$. It starts near one for an undamped QP and decreases toward zero as stronger boundary damping is required, matching the direction of optical-design damping-factor displays. This is a reporting conversion only: the solver continues using raw $\lambda$, and it is not capped or inverted inside the KKT system.

The direct Requirement objective is a sum of positive contributions, $f(x)=\sum_i c_i(x)$. Its SQP model uses the equivalent transformed residuals $r_i(x)=\sqrt{2c_i(x)}$, so $\frac{1}{2}\sum_i r_i^2=f(x)$. The resulting generalized Gauss-Newton model preserves the direct Requirement gradient while restoring cross-variable optical curvature,

$$
g=\sum_i \nabla c_i,\qquad
B_{\mathrm{GGN}}=\sum_i \frac{\nabla c_i\nabla c_i^\mathsf{T}}{2c_i}.
$$

The contribution denominator uses a numerical floor derived from the current mean positive contribution. This avoids an absolute fallback scale and keeps the model stable as individual requirements approach zero.

A reliable full accepted step that lowers the direct Requirement score by at least 10% is treated as an optical basin transition. The accepted design is retained, while the local Jacobian/Broyden/BFGS model, damping seed, Lagrangian multiplier/penalty state, rejection history, and measured-probe history are rebased before the next QP. The trust radius retains the larger of its measured post-accept value and the configured initial radius: derivative history is local to the old basin, but the accepted step and gain ratio remain valid evidence about step scale. Multiplier and penalty updates are suppressed for the remainder of the transition iteration so they cannot undo the rebase. Position-keyed base optical evaluations remain reusable because they do not depend on the Lagrangian state. This closes the observed same-point gap where a continued run remained tied to a contracted region and large `QPDamp`, while avoiding repeated loss of radius after consecutive large improvements. The threshold is configurable with `kktSqpBasinTransitionImproveRel`; smaller ordinary improvements continue using secant history.

When trust-region globalization is active, the persistent damping seed is held across accepted and rejected optical trials; the trust radius and temporary QP multiplier own step control. Persistent damping grows only after an actual QP/KKT solve failure. Legacy Nielsen accepted-step decay remains available outside trust-region globalization.

The reported `alpha` is normally `1` in trust-region mode because the radius and QP re-solve control step length. Values below or above `1` belong to the optional line-search/lookahead path; a constant `alpha=1` is therefore not evidence that globalization is inactive.

Repeated rejection at the current best point schedules a bounded partial Jacobian refresh. When the iterate has not moved, refresh columns rotate instead of repeatedly selecting the first columns; with the default three-column budget, a 12-variable model is covered over four refreshes. Full periodic refresh is suppressed during a rejection plateau and remains available on accepted trajectories.

The accepted-point Powell-BFGS curvature is retained during a rejection recovery that stays at the current best point, because neither the iterate nor the Lagrangian gradient has changed. It is reset only after an actual rollback to a different point. This prevents a three-rejection recovery cadence from repeatedly discarding curvature and restarting from the weak diagonal model.

QP failures and numerically tiny steps do not spin through the remaining iteration budget. The optimizer first promotes the best already-evaluated improving finite-difference probe, when one exists. Otherwise it performs at most one rotating partial-refresh pass over all variables and terminates if the refreshed model still cannot produce a trial step.

Trial identity uses the same rounded cache key as optical evaluation, not a looser displacement norm. At one accepted point, each trial key can be attempted only once. A bound-clamped, rounding-equivalent, or previously rejected candidate is therefore treated as no new evaluation and advances the bounded model-refresh counter. Legacy stagnation restarts are disabled in trust-region mode because resetting reject state at an unchanged point violates this finite-state invariant.

This follows practical trust-region SQP behavior: rejected trials do not trigger derivative evaluation, and cheap QP re-solves are preferred over repeated optical line-search evaluations.

Trust-region SQP routes a measured-score plateau directly into the finite outer recovery. The former high-damping Qcon escape is not allowed to move to an unmeasured design, clear the plateau state, and force another expensive Jacobian window before outer recovery can run.

The measured-score recovery from commit `bf3760cb` (2026-07-28, "Improve SQP convergence recovery and runtime batching") is retained inside the finite trust-region lifecycle. At the exact best point, all variables are measured in both finite-difference directions, the best improving coordinate is preserved, and a central direct-Requirement-score gradient is converted to a Design-Intent-scaled trust-region direction. The historical lookahead radii (`1`, `1.5`, `2`, `0.5`) are measured through the native batch evaluator. This path had later become reachable only when trust-region globalization was disabled, removing the recovery that produced the known score-in-the-teens result.

Finite-difference Jacobian construction already records the Requirement score and displacement of every evaluated perturbation. After a rejected model step, the trust-region route may directly accept the best non-violation-worsening improving observation at zero additional optical cost. It does not run a second all-variable central-difference score probe: a real v21 run showed that duplicate work alternating with normal iterations at roughly 66 seconds per probe, accepting shallow reductions that delayed the productive same-point rebase from about 10 minutes to 45 minutes. When no cached perturbation improves the score, the normal plateau watchdog is allowed to rebase the local model, and the outer multiscale recovery remains available for a true score plateau.

At a confirmed outer plateau, the coordinate poll additionally measures four radii derived from each variable's finite-difference step and Design Intent scale: the finite-difference radius, three times that radius, their geometric mean with the Design Intent scale, and the Design Intent scale itself. This is a bounded multiscale poll rather than a hardcoded global jitter. If it finds no lower Requirement score, the console reports the candidate count and lowest measured score before principal-axis and Qcon recovery continue. This distinguishes a locally flat finite-difference neighborhood from a coordinate poll that has exhausted the configured physical scale.

The same historical policy accepts an infeasible-to-feasible transition when either filter cost or direct score is non-worsening. This permits a temporary current-score increase needed to enter the feasible basin; tracked `bestScore` and `bestX` remain monotone, and ordinary violation-only progress still requires both cost and score to be non-worsening.

After same-point rebasing, the recovery first polls the two lowest-curvature principal axes of the generalized Gauss-Newton Hessian stored at the exact best-point key. A deterministic Jacobi eigensolve is applied to the Design-Intent-scaled Hessian, then each axis is mapped back to physical variables and measured in both signs at three trust-radius backtracks. This explores coupled all-variable directions outside both the gradient ray and the Qcon-only subspace. The stage is attempted once per exact best point, evaluates at most 12 candidates, and commits no seed unless its direct Requirement score improves the tracked best. Candidate evaluations are prefetched through the parity-checked native batch evaluator when available.

If the principal-axis poll finds no improvement, all configured Qcon modes and three Design-Intent-derived amplitudes are measured in one native batch rather than interleaving every mode with a new SQP/Jacobian window. A direct Requirement-score improvement is preferred. If every measured seed is initially worse, the lowest filter-merit seed whose Requirement score is no more than twice the tracked best is allowed one explicit four-iteration SQP proof window as a basin trial. The ceiling is relative to the measured best and can be configured with `kktSqpBasinTrialMaxScoreDeteriorationRel`; it prevents constraint merit alone from selecting an optically destructive seed such as the observed `381.934831` trial from a `65.3560` best. During the proof window, the outer plateau watchdog is suspended so a fresh Jacobian and ordinary accepted iterations can descend from the temporary seed. The tracked best point remains unchanged unless the trial trajectory actually beats its Requirement score. At the deadline, an unproductive trial restores the exact best point before final polish. The default recovery extension remains fixed rather than scaling with the Qcon mode count.

After Qcon restoration is exhausted, the final mixed-variable stage uses the same exact-best model's Cauchy direction. Its step length is the smaller of the one-dimensional quadratic minimizer and the Design-Intent-scaled trust boundary; three projected backtracks are measured, and no seed is committed unless its Requirement score improves the tracked best. This supersedes the earlier fixed-amplitude, two-sign mixed poll, which measured `99.814654` from a `65.3560` best point and therefore spent a proof window on a worsening seed.

The July 27 HEAD replay (`8d192f13`) is available only as an explicit diagnostic with `kktSqpHybridLegacy: true`. It is not part of the default policy because that revision predates optimizer expansion of `Field=ALL` and `Wavelength=ALL`; its reported score-in-the-teens trajectory is therefore not directly comparable with the current expanded Requirement score. When enabled, replay starts from an immutable Design Intent baseline captured when the project file is loaded. This is the attached/imported project, not the bundled `Examples/default-load.json` and not the mutable values present when a later Run starts. Blank active asphere/Qcon coefficients are normalized to zero by the same variable enumeration used by the strict phase, and every active numeric variable is resolved by its exact joint variable ID. Replay is skipped if the snapshot is missing or incomplete rather than silently substituting the persisted best values. The switch event reports the source filename plus baseline and Run-start vector fingerprints. The replay separates its current iterate from its monotone safety best: `currentX` starts at the imported-project vector, while the strict-phase variable vector, Requirement score, merit, and blocks snapshot are seeded as the best result. A replay that never beats the strict score cannot replace the persisted strict design. The July 27 profile disables lookahead, uses up to eight backtracking values (`1`, `0.5`, `0.25`, ...), and starts measured central-difference score recovery after the first rejected model step. Candidate evaluation still uses the current fixed-fidelity native batch path, and Stop remains shared. Projects already open when this diagnostic is enabled must be loaded once more to create the import baseline. Configure `kktSqpHybridLegacyIterations` to change its normal-`maxIterations` budget.

The legacy central-score probe reports its current replay score, monotone safety best, total and uncached candidate counts before evaluation. Its completion line reports the lowest measured candidate score and whether a point was accepted. A probe that accepts an improving replay point may run again at that new point; a probe that exhausts all candidates without improvement terminates replay immediately. It is not repeated from the same point with cached candidates, preventing an invisible reject/probe loop while preserving a genuinely descending historical trajectory.

After measured-score, low-curvature, Qcon, and mixed-Cauchy restoration candidates fail to improve the same strict best point, the default policy restores that best point and stops. A second SQP polish from the same point is redundant after the fresh rebase and exhaustive candidate measurements, so it is available only as an explicit diagnostic with `kktSqpBestPointPolish: true`.

## Evaluation Budget

The default KKT-SQP globalization evaluates one full trial and at most one contracted-radius retry. If both fail, an improving finite-difference probe already measured while refreshing the Jacobian can be accepted without another optical calculation. QP damping searches perform linear algebra only and do not invoke optical evaluation.

Optimizer Spot sampling is fixed at the configured ray-grid fidelity by default. Changing fidelity inside a run changes the objective and makes `Min.`, `Improv.`, and the actual/predicted reduction ratio incomparable across iterations. Multi-fidelity sampling remains available only with `adaptiveSpotSampling: true`.

This fixed-fidelity default also protects the quasi-Newton models. A Broyden update assumes that consecutive residual vectors come from the same function, while Powell-BFGS assumes consecutive gradients belong to the same objective. Switching the ray grid violates both secant equations and can spend the next expensive finite-difference refresh repairing a model that was invalidated administratively. This follows the Moré trust-region LM model-agreement requirement and the standard trust-region reflective lifecycle: fidelity can be reduced inside a consistently corrected surrogate method, but an uncorrected objective switch is not treated as an ordinary SQP iteration. Set both `adaptiveSpotSampling: true` and `adaptiveMtfSampling: true` only for explicit multi-fidelity experiments; production optimization derives one sampling level from the configured optimization grid and holds it fixed.

The previous extrapolating/backtracking order (`1`, `1.5`, `2`, `0.5`, `0.25`) remains available by setting `kktSqpTrustRegionGlobalization: false`. Trust-region mode can explicitly enable extrapolation with `kktSqpStepLookahead: true`.
